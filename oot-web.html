Save / load as text

Save states and the cartridge save file, as gzipped base64 text you can copy anywhere - a note, an email, a chat message - and paste back later.

Save state is the exact machine state, so it restores you mid-dungeon, mid-jump, anywhere. Cartridge save is the game's own save file (the three file slots), which survives core updates and works in other N64 emulators.
